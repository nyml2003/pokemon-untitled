# 图鉴三段场景与拨轮导航

> 分类：未来；更新：2026-07-26。
> 状态：`game-page-demo` 已实现第一版，待原生视觉验收后再接入正式运行时。

## 结论

图鉴不是后台式双栏页面，也不是多张卡片组成的横向轮播。

它是一段连续的游戏场景：先用竖向拨轮选择宝可梦，再查看资料，最后查看技能。资料和技能页面不重复展示大立绘，只保留收起的编号和 icon 作为当前位置提示。

```text
                     Right                     Right
Browse  ------------------------------>  Profile  --------->  Moves
竖向拨轮，3 个可见物种                    属性和种族值          技能虚拟列表
中心项：放大 icon + 名称 + 编号             收起的编号/icon 轨     收起的编号/icon 轨
邻近项：icon
                     Left                      Left
```

## 设计原则

- 世界画面不放固定 HUD。图鉴进入后才显示自己的场景。
- 不显示“暂停”“返回”“图鉴/INDEX”等固定标题。
- 不增加返回按钮。`Left` 和 `Cancel` 承担返回。
- 键盘是主输入。鼠标只允许点选可见的宝可梦或技能。
- 视觉关系由位置、资源和过渡表达，不用说明文字堆砌。
- `game-page-model` 只保存宝可梦、技能和种族值等事实。焦点与动画属于 `game-ui`。
- 图鉴主题使用 `POKEDEX_THEME`。不得复用基础页面的深蓝/黄色主题。

## 键位合同

| 位置 | 上/下/Home/End | 左 | 右 | Confirm |
| --- | --- | --- | --- | --- |
| Browse | 拨动物种索引 | 无 | 进入 Profile | 进入 Profile |
| Profile | 无 | 回到 Browse | 进入 Moves | 切换条形图/雷达图 |
| Moves | 移动技能索引 | 回到 Profile | 无 | 保持当前技能 |

点击物种后，`PageUiState` 必须先更新焦点和拨轮目标；之后的上下键从点击的索引继续。点击技能同理。

## 场景结构

### Browse

```text
              [ 160 icon ]

                 [ 320 icon ]
                  NAME
                 NO.001

              [ 160 icon ]
```

- 画面最多显示 3 个物种：中心项和上下各一个邻项。
- 中心物种使用 `320px` 的 `icon`；直接相邻项使用 `160px`。尺寸随拨轮位置连续插值。
- 只有中心项显示名称和 `NO.001` 形式的完整编号。邻近项不显示编号，避免文字与 icon 争夺焦点。
- demo 从全国图鉴 `#001` 开始；首项没有前置邻居，不能伪造绕回末尾的条目。
- Browse 与 Profile 之间，当前三项 icon 都会缩小并移动到位置轨的对应项；中心项落到当前项，邻项分别落到相邻位置。边界只转场实际存在的项。
- 共享转场的起点和终点都从当前 viewport 下的 Browse stage 与 rail 布局计算，不能依赖 `960x720` 专用坐标。
- 拨轮位置是连续整数毫单位。上下键一次移动一个索引，渲染层把连续位置换算为垂直像素偏移。
- 画面维持上下各一个邻居；首项和末项不伪造缺失的另一侧条目。
- 未发现物种保留暗色轮廓，不展示名称以外的伪造数据。

### Profile

```text
  251 icon       NO.253
  252 icon       NAME    [类型图标]
> 253 icon
  254 icon       [ 条形图 或 雷达图 ]
  255 icon
```

- 左侧轨只表示当前物种位置。它没有 action，也不能直接切换物种。
- Profile 不再重复 front 立绘。
- 种族值沿用共享 `stat_chart`：条形图以 256 为满值；雷达图显示 50、100、150 三个同心六边形，数值可以超出最外环。

### Moves

```text
  251 icon       [类别图标] 01 技能名
  252 icon       [类别图标] 02 技能名
> 253 icon       [类别图标] 03 技能名
  254 icon
  255 icon       当前技能的类型、威力、命中和 PP
```

- 技能列表使用 `KeyboardSingleColumnFixedHeightScrollView`。
- 只构建可见项目和前后预渲染窗口。
- 当前行使用主题选中色。类别图片保持原始 PNG 宽高比例。

## 转场与实现边界

`PokedexVisualState` 有两条独立轨道：

```text
section_position : Browse=0, Profile=1000, Moves=2000
wheel_position   : 物种索引 * 1000
```

- 左右切层只推进 `section_position`，默认时长 280ms。
- 上下拨动物种只推进 `wheel_position`，默认时长 200ms。
- 两条轨道使用相同的整数缓入缓出曲线。首帧只产生小位移，末帧精确停在目标位置。
- 新输入从当前视觉位置追踪下一个目标，不回跳到旧目标。
- 根场景 clip 所有横向偏移内容。非当前场景不挂 action，避免点击穿透。
- 过渡时相邻场景可以从边缘露出，但不能形成单独的全屏卡片或覆盖层。

文件职责如下：

```text
crates/presentation/game-view/src/page/pokedex/
├── mod.rs       根场景、横向位移、资源和格式化辅助函数
├── browse.rs    竖向拨轮
├── profile.rs   属性和种族值
├── moves.rs     技能虚拟列表
└── rail.rs      Profile/Moves 的只读物种位置轨
```

`game-ui` 负责 `PageFocus`、键位合同和两个动画目标。`game-view` 只读取模型与视觉状态，不保存选中索引。`game-native-plan` 继续只消费 `UiFrame`。

## 资源边界

现有可用资源：

- 拨轮、中心项和位置轨：`pokedex-icon/{number}` icon。
- 属性：现有 type icon。
- 技能类别：`ui/battle/move-category/*`。

第一版不需要新绘制的精灵表现资源。后续若补齐专用素材，资源槽位必须可被队伍页、图鉴中心项和剧情展示复用，不能把路径写死进单个页面。

## 验收

- `cargo test -p game-page-model -p game-ui -p game-view` 通过。
- `cargo run --bin game-page-demo -- --page-demo pokedex-seen-and-unseen` 中，Browse 中心项位于画面中心，邻居为 icon。
- `Right` 进入 Profile，继续 `Right` 进入 Moves；`Left` 按相反顺序返回。
- Profile/Moves 中没有重复 front 立绘、返回按钮或旧层级标题。
- 连续上下和左右输入不跳层，不产生重复 `UiKey`，并保持性能日志和退出报告。
- 原生视觉验收确认小窗口下文本、类型图标、技能类别图片和雷达图不重叠。

## 非目标

- 不改世界场景 HUD。
- 不在通用 UI kit 中加入图鉴业务状态。
- 不把页面转场改成 shader 特效。
- 不在本阶段补齐训练家或宝可梦专用表现素材。
- 不在未通过 demo 验收前接入正式 `game-host`。

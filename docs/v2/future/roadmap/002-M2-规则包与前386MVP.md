# M2：规则包与前 386 MVP

> 分类：未来；最后整理：2026-07-22。
> 状态：本地实现与验证完成；发布排序仍等待 M1 的 Windows 原生验收。

## 目标与冻结面

M2 将当前第三世代风格的确定性实现冻结为 `legacy-gen3@1`，而不是宣称已经拥有“最新世代”规则。它限定原始默认形态且全国图鉴号在 `1..=386`，并只允许当前 `battle-domain` 可执行的属性、能力和招式效果进入产品队伍。

现代数据源中的字段不自动获得资格。例如 `Ralts` 当前带有 `fairy` 属性，R0 会以 `UnsupportedType` 拒绝，而不会在运行时把它悄悄当作第三世代超能力属性。规则升级必须新建规则包及兼容策略，不能修改 `legacy-gen3@1` 的含义。

## 已知边界

- 这不是完整第三世代模拟。规则包只准入已在当前状态机中实现的招式效果与能力映射；未支持项在组队前拒绝。
- `ThinSliceContent::standard()` 仍保留为测试/兼容构造器；产品 host 已从 `assets/content/starter-region/content.json` 加载 `starter-region@1`。静态事件 DSL 仍属于 M3 后续工作。
- `SaveEnvelope` 为通用保存容器，规则引用为可选字段；产品入口始终写入并验证该字段，以保留基础状态工具的独立性。
- demo `GameSession` 的随机展示队伍不是产品内容允许表；M2 的范围是当前产品薄切片和可复用规则包合同。

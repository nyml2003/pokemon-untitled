## 当前执行入口

当前应从 [路线图](roadmap/README.md) 开始。M1 的代码与 Linux 验证已完成，但仍待 Windows 原生验收；M2 已在本地完成 `legacy-gen3@1` 规则包、首区域准入和固定输入回放。下一项未开始的产品工作是 M3 的静态内容包与事件 DSL。

后续里程碑不能绕过这一前置条件：模型生成地图或 NPC DSL、规则包升级、训练师 AI 与内容包发布都依赖真实战斗结果能原子回写到同一份长期状态。

## 维护规则

- 产品目标发生实质改变时，先更新 `product/`，再调整受到影响的里程碑。
- 工作包完成且有代码、测试或验收依据后，在路线图中标记完成；不要把完成历史继续混在未来目标中。
- 未来设计实现并被验证后，将可证明的事实移入 `docs/v2/current/` 或相应 crate 文档。
- 日常命令、格式化、检查、测试与原生验收通过项目 `ops` 入口执行。
